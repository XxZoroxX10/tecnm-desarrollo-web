Regla de Oro del Desarrollador

Si tu código solo está en tu Codespace, NO EXISTE.

Un Codespace puede cerrarse o borrarse por inactividad. El único lugar seguro y evaluable es tu repositorio en GitHub.

Cómo Funciona Git: La Metáfora Postal

  1. Working Directory: Tu mesa de trabajo (los archivos que editas en el editor).
  2. Staging Area (git add): Colocar los archivos dentro de la caja de envío.
  3. Commit (git commit): Sellar la caja y escribirle una etiqueta con la descripción exacta del contenido.
  4. Push (git push): El camión de mensajería que traslada la caja a GitHub.

Los 4 Comandos Esenciales


# 1. ¿Qué archivos modifiqué o creé?
git status

# 2. Preparar el archivo específico para el envío
git add app_http_test.py

# 3. Guardar el cambio con un mensaje claro
git commit -m "feat: agrega soporte para metodo PATCH en el despachador"

# 4. Enviar a tu repositorio en GitHub
git push origin main
